## 🧪 Как тестировать

1. **Зарегистрируйтесь** на странице `/register`
   - Заполните: First Name, Last Name, Email, Password

2. **Вы автоматически залогинитесь** и будете на главной странице

3. **В хедере** увидите "Имя Фамилия"

4. **Кликните на имя/фамилию** → переходите на `/profile`

5. **На странице профиля:**
   - Видите полную информацию (ID, Email, Имя, Фамилия)
   - Переключайтесь между вкладками
   - Нажимайте кнопку "Выход" → выходите, переходите на логин

## 🔄 Жизненный цикл данных

### При регистрации:
```
frontend POST /register 
  → backend создаёт user
  → фронтенд вызывает POST /login
  → backend возвращает { token, user_id, email, firstName, lastName }
  → AuthContext сохраняет в состояние + localStorage
```

### При открытии профиля:
```
/profile 
  → useAuth() даёт { firstName, lastName, userEmail, userId }
  → компонент отображает информацию
```

### При выходе (logout):
```
нажимаем "Выход" на профиле
  → AuthContext удаляет всё из localStorage и состояния
  → переходим на /login
  → пользователь разлогинен
```

### При перезагрузке страницы:
```
useEffect в AuthProvider
  → читает localStorage
  → восстанавливает состояние
  → пользователь остаётся залогинен
```
